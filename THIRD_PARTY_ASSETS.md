# Asset provenance and historical references

The authored JavaScript, CSS, server code and new SVG drawings are covered by the root MIT license. The following external materials are separate from that grant.

| Material | Files | Source and rights information |
| --- | --- | --- |
| ChicagoFLF font | `public/fonts/ChicagoFLF.ttf` | [Font Library](https://fontlibrary.org/en/font/chicagoflf); public-domain designation. The downloaded notice is included as `ChicagoFLF-LICENSE.txt`. This is a substitute, not Apple's original bitmap font. |
| NineIcons bitmaps | `public/assets/nineicons-*.png` | [Platinum9 / NineIcons](https://github.com/grassmunk/Platinum9). Original artwork remains subject to its rights holders. No general permissive asset license was established. |
| Historical application and folder icons | `public/assets/original-*.png` | [GUIdebook Gallery](https://guidebookgallery.org/screenshots/macos90/), preserving historical Mac OS appearance. Apple artwork is not relicensed by this project. |
| Desktop reference | `public/assets/platinum-desktop-reference.png` | [Mac OS 9.0 desktop screenshot](https://guidebookgallery.org/pics/gui/desktop/empty/macos90-1-1.png). The compositor extracts the clean 128×128 wallpaper tile at (0,20). The screenshot is reference material, not a complete interactive background. |

Historical names and marks identify the system being recreated. This project is not affiliated with or endorsed by Apple or Microsoft. Original software binaries, ROM images and system disk images are not included.

## Interface references

- [Mac OS 9.0 screenshot collection](https://guidebookgallery.org/screenshots/macos90/): desktop, Finder, dialogs and panels.
- [Inside Macintosh: GetMBarHeight](https://dev.os9.ca/techpubs/mac/Toolbox/Toolbox-128.html): Roman-script menu-bar geometry.
- [Apple TIL 60499](https://til-2001.mirror.kb1max.com/techinfo.nsf/artnum/n60499/index.html): application locations.
- [Apple TIL 60500](https://til-2001.mirror.kb1max.com/techinfo.nsf/artnum/n60500/index.html): control panels.
- [Apple TIL 58092](https://til-2001.mirror.kb1max.com/techinfo.nsf/artnum/n58092/index.html): Appearance controls.
- [Apple TIL 60334](https://til-2001.mirror.kb1max.com/techinfo.nsf/artnum/n60334/index.html): QuickTime 4 interface reference.
- [WebGPU specification](https://gpuweb.github.io/gpuweb/): current graphics API contract.

Several extras, including Drawing Pad, Font Viewer and the optional Puzzle, are useful browser additions rather than claims about the exact stock OS 9 installation inventory. Hardware-dependent applications and original bundled software varied by Macintosh model and installation disc.
